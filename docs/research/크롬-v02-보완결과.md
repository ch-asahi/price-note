# 크롬 테스트 도구 v0.2 보완 결과

## 구현한 보완

- 실제 열린 페이지의 meta → JSON-LD/페이지 JSON → 알려진 window 데이터 속성을 검사한다.
- 후보별 상품 필드, 값, method, kind, 위치를 결과 JSON에 기록한다.
- 값 충돌 또는 미발견 항목만 클릭 지정하며, 숨은 데이터가 틀린 경우 명시적으로 클릭 위치로 대체할 수 있다.
- 클릭 위치를 사이트 호스트별 chrome.storage.local에 저장하고 다음 읽기에 재사용한다.
- 단위 가격·배송비·쿠폰·회원 혜택 등 제외 필터를 숨은 데이터와 클릭 읽기에 적용한다. 라벨이 분리돼 의미를 알 수 없는 값은 사용자의 화면 비교가 여전히 필요하다.
- 팝업을 닫고 클릭한 뒤 다시 열어도 결과와 비교 입력을 유지한다.
- 원본 페이지 JSON이나 전체 window를 덤프하지 않는다. 함수/getter/eval을 사용해 페이지 데이터를 실행하지 않는다.

## 개발 환경 확인

JavaScript 구문 검사 및 테스트 데이터 기반 회귀 검사 통과:

- 메타 값·위치, 상대 이미지 URL
- JSON-LD Product/Offer, 정가와 판매가 분리
- 다른 상품 ID·추천·쿠폰·단위 가격·배송 금액 제외
- __NEXT_DATA__, 인라인 JSON 대입, 알려진 window 변수
- getter 미실행, 임의 JavaScript 미평가
- 후보 충돌 시 자동 선택 중지, 최고가를 정가로 사용하지 않음
- 클릭 위치 재사용 및 모호하거나 금지 값인 위치 거부

실제 Chrome 설치/클릭 및 실제 쇼핑몰 숨은 데이터 검사는 아직 사용자 실행이 필요하다. 이전 v0.1 결과는 숨은 데이터를 검사하지 않았으므로 이번 버전으로 다시 검사해야 한다. 실제 페이지에서 특정 숨은 데이터가 발견됐다고 보고하지 않는다.

정식 가격 이력·차트·CSV·알림은 아직 구현하지 않았다. 사용자의 재테스트 결과 보고와 확인을 받은 뒤 진행한다.
