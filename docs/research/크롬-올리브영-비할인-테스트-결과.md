# 올리브영 비할인 상품 테스트 검토

**후속 확인:** 사용자가 화면에 별도 정가 없이 판매가 85,500원만 표시됐다고 확인했다. 정가는 null로 처리한다. 중복 지정 방지 보완을 포함해 정식 1.0 구현을 진행했으며, 실제 Chrome 설치 검증은 별도로 미확인이다. 아래는 후속 확인 전의 진단 기록이다.

검토 파일: price-read-test-올리브영-1795408369350.json

상품: ENHYPEN - THE SIN : PARALLEL WORLD (ENGENE ver.) (DAY Set)
상품 ID: B000001006070

상품명과 이미지는 og 메타태그에서 읽었다. 판매가는 저장된 클릭 위치에서 85,500원으로 읽었고 mappingErrors는 빈 배열이다.

그러나 정가와 판매가가 동일한 CSS 선택자를 사용한다. 따라서 이 결과를 별도 정가 85,500원 확보로 해석할 수 없다. 화면에 정가가 따로 표시되지 않은 상품이라면 정가는 null, 판매가만 85,500원으로 처리해야 한다. 이 파일의 비교란도 미확인 상태다.

테스트 도구는 같은 화면 요소를 정가와 판매가에 중복 지정하는 것을 거부하고, 정가 근거(취소선 또는 정가 라벨)가 없는 요소를 정가로 읽지 않도록 보완했다. 기존 잘못 저장된 위치를 재사용하는 경우에도 정가를 비우고 오류를 남긴다. 같은 위치로 두 가격을 기록한 보고서는 가격 기준 검사에서 통과시키지 않는다. 정가·판매가 숫자가 같더라도 실제로 별도 정가 필드가 있는 경우 자체를 금지하지는 않는다.

회귀 검사로 별도 정가 근거 없는 요소 거부, 취소선 정가 허용, 동일 요소 중복 거부를 확인했다. 실제 수정본의 크롬 검사는 아직 하지 않았다.

사용자가 실제 화면에 별도 정가는 없고 판매가 85,500원만 표시된 것인지 확인해 주면, 이 상품의 결과 의미를 확정할 수 있다. 이 결함을 발견한 현재 상태에서 추가 테스트 전체를 통과로 선언하거나 정식 구현을 시작하지 않는다. 조건부 구현 승인은 유지된다.
