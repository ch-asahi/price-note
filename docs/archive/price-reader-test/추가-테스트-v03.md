# 추가 테스트 v0.3

## 확정한 가격 기준

- 판매가: 쿠폰·회원등급 할인·카드 할인을 적용하지 않은, 누구에게나 보이는 공통 할인가.
- 세일 없는 상품의 판매가: 일반 판매 가격. 별도의 정가가 표시되지 않으면 정가는 비워 둔다. 판매가를 정가로 복사하지 않는다.
- 옵션: 목록의 첫 번째 상품 옵션을 기준으로 한다. '옵션을 선택하세요' 같은 안내 항목은 옵션이 아니다. 여러 단계면 각 단계의 첫 번째 상품 항목으로 조합한다. 첫 번째 상품 옵션이 품절이면 자동으로 두 번째로 대체하지 말고, 품절과 가격 확인 불가를 메모한다.
- 옵션별 금액이 다르면 `옵션 가격 다름`을 표시한다. 가격 기준을 지키려면 옵션 선택 후 다시 읽는다. 수량은 기본 1개(기획 세트는 해당 구성 한 세트) 기준으로 비교한다.
- 로그인 상태는 사용자가 직접 확인한다. 같은 상품·같은 첫 번째 옵션의 로그인/로그아웃 보고서를 15분 안에 저장하면 가격을 비교한다. 상태나 비교 대상이 없으면 미확인으로 둔다. 차이가 있으면 시간차에 따른 가격 변동 가능성도 표시한다.

기존 버전의 숨은 가격이 선택한 옵션 가격을 반영하지 않을 수 있다. 화면 값과 다르면 '이 값이 다름 · 클릭으로 수정'으로 현재 일반 판매가를 지정한다. 옵션은 확장 프로그램이 자동으로 누르지 않으며, 사용자가 평소처럼 선택한다. 추가 서버 요청이나 로그인 자동화는 없다.

## 업데이트

1. `chrome://extensions`에서 가격 읽기 사전 테스트의 새로고침을 누른다.
2. 버전이 **0.3.0**인지 확인한다.
3. 상품 페이지를 새로고침하고, 첫 번째 옵션을 직접 선택한 다음 검사한다.

## 상품 구성

올리브영은 추가 2~3개로 아래 유형이 포함되도록 검사한다. 한 상품이 여러 유형에 해당해도 된다.

- 세일 중인 상품
- 세일 없는 상품
- 옵션별 가격이 다른 상품

무신사는 추가 1~2개를 검사한다. 기존에 저장한 클릭 위치가 다른 상품에서도 맞는지 보려면 새 상품에서 처음에는 클릭 위치를 바꾸지 말고 읽는다. 틀리면 실패 상황을 메모한 후 수정한다.

## 각 상품에서 할 일

1. 첫 번째 옵션을 선택하고 화면의 정가·공통 판매가를 확인한다.
2. **숨은 데이터 검사 / 다시 읽기**를 누른다.
3. 읽지 못하거나 틀린 항목만 클릭으로 지정한다.
4. 전체 결과, 실제 화면 정가·판매가, 상품명·이미지 일치 여부를 작성한다.
5. 새로 추가된 **가격 기준 확인**에서 판매가 종류, 로그인 상태, 옵션 가격 차이, 첫 번째 옵션 이름과 선택 확인을 채운다. 옵션이 없으면 '옵션 없음'만 선택한다.
6. 메모에 상품 유형(세일/세일 없음/옵션 여러 개)과 저장 위치 재사용 성공·실패를 남긴다. 정가 미표시는 전체 결과를 일부 일치로 표시하고 메모한다.
7. JSON을 상품별로 저장한다. 모든 추가 결과 파일을 대화에 첨부한다.

팝업의 **가격 기준 확인** 안내는 누락된 확인 사항을 알려 준다. 실패 진단 파일도 저장할 수 있으므로 값이 틀려도 보내면 된다. **다시 읽기**를 누르면 새 측정으로 취급해 이전 화면 비교와 가격 기준 입력을 초기화한다. 클릭 지정을 위해 팝업을 닫는 경우에는 입력을 유지한다.

## 로그인 전후 비교도 하려면 (선택)

한 상품에서 동일한 옵션을 유지하고 로그인 상태를 바꿔 각각 새로 검사·입력·JSON 저장한다. 로그인/로그아웃은 직접 한다. 확장 프로그램을 재설치하거나 다른 Chrome 프로필/시크릿 창을 쓰면 로컬 저장 공간이 달라 자동 대조되지 않을 수 있다. 그 경우 두 JSON을 보내면 함께 검토할 수 있다.

자동 대조용 기록은 이 PC에 최대 100건만 보관하며, 가격 기준을 확인한 테스트를 JSON으로 저장할 때 추가한다. 날짜별 가격 추적 기능은 아니다. 반대 상태의 최근 관측이 없으면 로그인 영향이 없다고 추정하지 않는다.

## 다음 단계

추가 보고서에서 가격 기준 일치와 여러 상품에서의 읽기 안정성을 확인한다. 틀린 가격·옵션을 고르거나 재사용이 실패하면 파서를 보완하고 다시 확인한다. 테스트가 통과하면 사용자 지시에 따라 별도 승인 질문 없이 정식 확장 프로그램 구현을 진행한다.
