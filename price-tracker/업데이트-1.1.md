# 가격노트 1.1 업데이트

기존 설치 폴더의 소스를 업데이트했다. `chrome://extensions`에서 **가격노트 카드의 새로고침**을 누르고, 열어 둔 상품 페이지도 새로고침하면 적용된다. 버전은 **1.1.0**이다. 같은 폴더에서 새로고침하면 기존 상품과 가격 이력은 유지된다. 삭제·재설치는 필요하지 않다.

## 변경 내용

1. 기본 화면은 오늘 기록 현황과 상품 목록으로 시작한다. 저녁 알림 설정은 상단 **설정**으로 들어간 화면에만 표시하고, **돌아가기**로 기본 화면에 복귀한다.
2. 정상 자동 기록 후에는 패널을 접어 두고 **오늘 기록 완료** 토스트를 2.5초 표시한다. 같은 방문의 중복 읽기 때문에 토스트가 반복되지 않는다. 수동으로 가격노트 버튼을 누르면 언제든 패널을 열 수 있다.
3. 읽기 실패나 옵션 기준 미확인, 또는 이전 기록의 정가/판매가와 **30% 이상** 차이가 나면 패널을 펼친다. 30% 변동 값은 확인 전에는 기존 기록을 덮어쓰지 않는다. 화면과 값이 맞으면 저장 버튼으로 확정한다. 별도 정가가 생기거나 없어지는 것은 숫자 간 변동으로 간주하지 않는다.
4. 상품 영역에 실제 표시된 행사 문구를 읽어 그날 `eventName`으로 저장한다. 타임특가·무진장·올영세일·올영픽·블랙프라이데이 등 사이트별로 등록한 이름을 확인한다. 숨은 메타 상품명에서 행사명을 추측하지 않고, 추천/리뷰/헤더/내비게이션 영역은 제외한다. 못 읽으면 빈 문자열이다. 행사명을 새로 읽었다고 과거 기록까지 채우지 않는다.
5. 그래프 점에 마우스를 올리면 날짜·정가/판매가·행사명이 나온다. 행사명이 없으면 날짜와 가격만 나온다. 기록 표와 상세 정보에서도 행사명을 볼 수 있고, 직접 입력 시 보정할 수 있다.
6. 기록 날짜가 14개 미만이면 역대 최저가와 기록 평균가는 **—**로 표시한다. 가격 기록 자체는 그대로 보관한다.
7. 그래프 세로축은 1·2·5 배수의 정수 단위 눈금을 사용한다. 예를 들어 40,000원·50,000원·60,000원처럼 표시한다.
8. 요약에 **쇼핑몰 표시 할인율**을 추가했다. 저장된 정가 대비 판매가로 계산하며 소수점 한 자리로 반올림한다. 정가가 없으면 **—**다. 쇼핑몰의 반올림 방법이나 쿠폰 포함 광고 수치와는 다를 수 있다.
9. 상품 상단의 배지는 판정 배지 하나만 남겼다. 로그인·로그인 영향·옵션·행사 정보는 **상세 정보** 안으로 옮겼다. 목록의 오늘 기록 상태는 배지 대신 일반 글자로 표시한다.

## 백업 호환

새 CSV는 행사명 열을 추가한 형식 2로 저장한다. 기존 1.0의 형식 1 CSV도 가져올 수 있고, 기존 기록의 행사명은 빈칸으로 처리한다. Chrome 로컬 저장 구조와 기존 기록은 유지한다. 최신 CSV는 이전 버전 프로그램에서 읽지 못할 수 있으므로 복원 시 1.1을 사용한다.

## 확인한 사항

구문 검사, 30% 경계와 덮어쓰기 방지, 14일 전후 요약, 할인율, 정수 눈금, 행사명 표시/제외와 SVG 이스케이프, 행사명 CSV 왕복 및 기존 CSV 복원을 검사했다. DOM/Chrome API 모의 환경에서 설정 화면 전환, 배지 한 개, 정상 토스트 2.5초 후 숨김 및 중복 억제, 읽기 실패/가격 급변 시 패널 열림을 확인했다.

실제 Chrome에서의 새 화면과 행사 배지 DOM은 이번 변경에서 직접 관찰하지 않았다. 사용자가 기존 1.0의 실제 가격 기록 정확성을 확인해 준 상태에서 읽기 핵심은 유지했다. 행사명이 안 잡히는 상품은 원격 요청으로 보완하지 않고 빈칸으로 남긴다.
