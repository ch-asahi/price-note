# 가격 읽기 테스트 v0.3

**추가 테스트는 [v0.3 가격 기준·옵션·로그인 안내](추가-테스트-v03.md)를 먼저 확인하세요.** 현재 버전은 0.3.0입니다. 아래의 일반 설치·클릭 사용법은 같으며, '다시 읽기'를 누르면 이전 측정의 비교 입력은 초기화됩니다.

정식 추적기 구현 전에 실제 크롬 페이지의 데이터를 확인하는 도구입니다. 상품 기록 이력·그래프·CSV·저녁 알림 기능은 아직 구현하지 않았습니다. 서버나 API 키는 필요 없습니다.

## 이미 설치했다면 업데이트하기

1. 크롬 주소창에서 `chrome://extensions`를 엽니다.
2. **가격 읽기 사전 테스트** 카드의 새로고침(둥근 화살표)을 누릅니다. 권한 확인이 표시되면 추가된 로컬 저장 권한을 확인합니다.
3. 확장 프로그램 상세 정보에서 버전이 **0.3.0**인지 확인합니다.
4. 열어 둔 상품 페이지도 새로고침하고 상품명과 가격이 나타날 때까지 기다립니다.

## 처음 설치한다면

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. `압축을 푼 폴더\docs\archive\price-reader-test` 폴더를 선택합니다. `manifest.json`이 바로 들어 있는 폴더입니다.
5. 오른쪽 위 퍼즐 아이콘에서 **가격 읽기 사전 테스트**를 고정합니다.

공식 설치 안내: https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world

## 1. 숨은 데이터부터 검사하기

1. 무신사 상품 상세 페이지를 평소처럼 엽니다. 원하는 옵션을 선택합니다.
2. 상품명·일반 판매가·정가를 화면에서 확인하고 메모합니다. 정가가 표시되지 않으면 **미표시**로 둡니다.
3. 확장 프로그램 아이콘을 누르고 **숨은 데이터 검사 / 다시 읽기**를 누릅니다.
4. 상품명·대표 이미지·정가·판매가 네 칸을 확인합니다. 각 칸에 값, **숨은 데이터/클릭**, 구체적인 읽기 위치가 표시됩니다. 이미지 주소는 텍스트로만 보여 줍니다.
5. **검사 위치·후보·제외 사유 전체 보기**를 펼치면 메타태그·JSON-LD·페이지 JSON·window 변수 검사 내역을 볼 수 있습니다.

숨은 데이터의 서로 다른 값이 충돌하면 임의로 고르지 않고 **못 찾음 / 후보 충돌**로 표시합니다. 추천·다른 상품 ID·쿠폰·배송·단위 가격으로 판별한 후보는 `hidden.rejected`에 값과 제외 사유를 남깁니다. 정가를 판매가로 대체하지 않습니다.

페이지에 메타데이터가 있어도 화면과 갱신 시점이나 옵션이 다를 수 있습니다. 표시된 가격이 현재 선택한 옵션의 일반 판매가인지 꼭 비교합니다. 숨은 데이터를 찾았다는 것만으로 성공 판정하지 않습니다.

## 2. 부족한 항목만 클릭으로 지정하기

1. **못 찾음 / 후보 충돌**로 나온 항목의 **클릭 지정** 버튼을 누릅니다.
2. 팝업이 닫히고 상품 화면 오른쪽 위에 안내가 나타납니다.
3. 화면에서 그 항목을 한 번 클릭합니다. 상품명은 글자 영역, 가격은 해당 숫자만 있는 작은 영역, 이미지는 대표 이미지 자체를 클릭합니다. 영역 위로 마우스를 움직이면 테두리로 표시됩니다.
4. 저장되면 안내가 사라집니다. 확장 프로그램 아이콘을 다시 열어 결과를 확인합니다.
5. 나머지 부족한 항목도 반복합니다. 화면에 정가가 없으면 정가를 지정하지 않아도 됩니다.

숨은 데이터가 있었지만 실제 화면과 다른 경우에는 **이 값이 다름 · 클릭으로 수정**을 누릅니다. 이 경우 해당 필드의 숨은 데이터를 사용할 수 없는 것으로 보고 클릭 위치를 우선하도록 저장합니다.

**단위 가격(100ml당 등), 배송비, 쿠폰 적용가, 회원 혜택가, 적립금**으로 판별된 영역은 선택을 거부하고 이유를 알려 줍니다. 다른 위치를 클릭하거나 Esc로 취소할 수 있습니다. 사이트가 주변 라벨을 멀리 떨어뜨려 놓은 경우 자동 필터만으로 의미를 확정할 수 없으므로 사용자 비교도 필요합니다.

### 다음 상품에서 재사용 확인하기

같은 사이트의 다른 상품을 열고 **숨은 데이터 검사 / 다시 읽기**를 누릅니다. 클릭을 다시 하지 않아도 저장된 위치에서 현재 값을 읽습니다. 현재 화면과 맞는지 확인합니다.

- 클릭 위치는 `chrome.storage.local`에 사이트 호스트별로 저장합니다. 무신사와 올리브영, PC와 모바일 주소는 구분합니다.
- 숨은 데이터가 유효하고 단일 값이면 먼저 사용합니다. 사용자가 틀렸다고 표시한 필드는 저장된 클릭 위치를 우선합니다.
- 저장 위치가 사라졌거나 여러 곳과 일치하거나 금지 가격이 나오면 재사용하지 않고 오류를 표시합니다.
- 사이트 구조가 바뀌면 같은 위치가 다른 내용을 가리킬 수도 있습니다. 새 상품에서 화면 비교가 필요합니다.
- 다시 지정하려면 각 항목의 수정 버튼을 누릅니다. 전체 위치를 지우려면 **이 사이트 클릭 위치 초기화** 후 다시 검사합니다.

## 3. 실제 화면 비교 결과 저장하기

1. 확장 프로그램 아래 **전체 결과**를 선택합니다.
2. **화면의 정가**, **화면의 판매가**를 실제 값으로 입력합니다. 정가 미표시는 비워 둡니다.
3. 메모에 상품명·이미지 일치 여부, 옵션·수량·용량·색상, 할인 조건을 적습니다. 정가가 없거나 이미지 확인이 어려우면 일부 일치로 표시하고 이유를 남깁니다.
4. **테스트 결과 JSON 저장**을 누릅니다.
5. 올리브영에서도 반복하고 JSON 두 개를 이 대화에 첨부합니다.

비교 입력과 현재 사이트의 최근 테스트 결과는 이 PC에 저장되므로 클릭 지정 때문에 팝업이 닫혀도 유지됩니다. 사이트당 최근 테스트 결과 한 건만 보관하며 가격 이력은 아닙니다. 다른 상품을 검사하면 최근 결과는 바뀌므로 상품별 비교가 끝나면 파일로 저장하세요.

## 결과 JSON 보는 법

| 위치 | 내용 |
| --- | --- |
| `hidden.candidates` | 찾은 상품명·이미지·정가·판매가, 읽은 종류와 정확한 경로 |
| `hidden.rejected` | 제외한 금액/후보와 이유 |
| `hidden.sources` | 검사한 메타·스크립트·변수별 상태 |
| `hidden.truncated` | 용량·개수 제한 때문에 전체를 검사하지 못했는지 |
| `selected` | 항목별 최종 선택값. `method: hidden`은 숨은 데이터, `method: click`은 클릭 위치 |
| `selected.*.kind` | `meta`, `json-ld`, `page-json`, `window`, `picked-element`, `saved-selector` |
| `selected.*.location` | 메타태그, JSON 경로 또는 CSS 선택자 |
| `mappingErrors` | 저장 위치를 재사용하지 못한 이유 |
| `comparison` | 사용자가 직접 입력한 화면 가격과 비교 결과 |

## 검사 범위와 한계

- 크롬에서 실제 열린 페이지의 `og:title`, `og:image`, `product:price` 계열 메타태그를 검사합니다.
- `application/ld+json`, `application/json`, `__NEXT_DATA__` 스크립트 및 알려진 변수에 대입된 순수 JSON 리터럴을 검사합니다.
- `__NEXT_DATA__`, `__INITIAL_STATE__`, `__PRELOADED_STATE__`, `__NUXT__`, `__APOLLO_STATE__`, `goodsInfo`, `goodsData`, `productInfo`의 데이터 속성을 페이지의 MAIN 환경에서 읽습니다. 검사할 이름과 사이트별 상품 필드명은 각 사이트 파일에서 추가할 수 있습니다.
- 전체 window, 쿠키, 로컬스토리지, 계정 정보를 수집하지 않습니다. 원본 상태 JSON을 통째로 저장하지 않고, 추출한 상품 필드와 위치만 결과로 남깁니다.
- getter, 함수, 임의의 페이지 코드, JavaScript 표현식은 실행하지 않습니다. Next Flight 스트림을 디코딩하지 않습니다. 따라서 모든 숨은 데이터를 완전히 검사했다고 보장하지 않으며 검사 범위와 건너뛴 항목을 결과에 표시합니다.
- fetch/XHR, 외부 이미지 로딩, 자동 로그인, 서버 통신, 우회를 추가하지 않았습니다.

MAIN 환경 공식 문서: https://developer.chrome.com/docs/extensions/reference/api/scripting

## 코드 위치

- `readers/musinsa.js`: 무신사 필드명·상품 식별 키·검사할 전역 변수 목록
- `readers/oliveyoung.js`: 올리브영 필드명·상품 식별 키·검사할 전역 변수 목록
- `readers/hidden.js`: 공통 숨은 데이터 검사
- `readers/dom.js`: 클릭 선택·저장 위치 재사용·금액 제외 처리
- `popup.js`: 검사 실행·결과 표시·비교 입력·JSON 저장
- `tests/readers.test.cjs`: 네트워크 없는 테스트 데이터로 하는 회귀 검사

개발자 검사는 프로젝트 상위 폴더에서 `node price-reader-test/tests/readers.test.cjs`로 실행합니다. 이 검사가 실제 쇼핑몰 검증을 대신하지는 않습니다.
