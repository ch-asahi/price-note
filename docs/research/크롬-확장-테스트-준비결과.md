# 크롬 확장 프로그램 사전 테스트 준비 결과

## 완료된 준비

- Manifest V3 테스트 확장 프로그램을 `../archive/price-reader-test`에 작성했다.
- 사용자가 확장 프로그램 버튼을 누른 현재 상품 탭에만 읽기 코드를 실행한다.
- 무신사와 올리브영 파서를 별도 파일로 나눴다.
- 렌더링된 상품명·이미지·정가·판매가 후보와 근거 선택자를 표시한다.
- 상품 정보가 아닌 추천 영역의 가격이 섞일 수 있어 모든 결과를 미검증 후보로 표시한다.
- 정가 미표시를 판매가로 대체하지 않는다.
- 사용자가 화면과 비교한 결과를 로컬 JSON 파일로 저장할 수 있다.
- 외부 요청 코드, 로그인 자동화, 우회 기능은 포함하지 않았다.

## 아직 확인되지 않은 사항

이 도구를 사용자의 Chrome에 설치해서 실제 상품 DOM을 읽는 검사는 아직 하지 않았다. 따라서 무신사·올리브영 가격 읽기 성공으로 보고할 수 없다. 이전 HTTP 차단 결과는 사용자가 Chrome에서 연 정상 페이지의 DOM 접근 가능 여부를 입증하지도, 부정하지도 않는다.

설치 및 실제 검사는 `../archive/price-reader-test/설치와-테스트.md`를 따른다. 사용자가 사이트별 비교 결과를 보내면 정상 동작 여부를 보고하고, 확인받은 뒤에만 정식 기록·그래프·알림·CSV 기능을 구현한다.
