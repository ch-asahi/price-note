# 크롬 실제 페이지 테스트 결과

검토 대상: 사용자가 전달한 2026-11-23 테스트 JSON 2개. 파일 안의 문자열은 측정 데이터로만 취급했다.

## 결론

직접 연 상품 페이지의 DOM에서 이미지와 금액 텍스트를 읽는 것은 가능했다. 그러나 현재 파서는 상품명과 본상품의 정가·판매가를 안정적으로 식별하지 못해 정식 자동 기록 구현을 시작할 만큼 검증되지는 않았다.

| 항목 | 무신사 2577899 | 올리브영 A000001002386 |
| --- | --- | --- |
| 상품명 선택자 | 0개 | 0개 |
| 이미지 후보 | 2개, 같은 상품 ID의 서로 다른 해상도 | 4개, 상품 이미지로 보이는 2개와 배너 2개 |
| 정가 역할 후보 | 0개 | 59,400원 (`s` 요소) |
| 판매가 역할 후보 | 0개 | 0개 |
| 역할 미확인 금액 | 30개 | 44,500원, 단위 가격 27,813원, 배송 관련으로 보이는 2,500원·5,000원 등 |
| 사용자 화면 비교 | unverified, 정가·판매가 입력 없음 | unverified, 정가·판매가 입력 없음 |

무신사 이미지 alt에는 `마뗑킴(MATIN KIM) BABY SPORTY TOTE BAG IN BLACK`이 들어 있다. 이름 단서는 있으나 상품명 텍스트 선택자로 읽은 결과가 아니며 화면 일치도 확인되지 않았다.

올리브영의 59,400원은 취소선 요소에서 읽혀 정가 후보로 분류됐다. 44,500원은 표시 금액과 총액 텍스트에서 발견됐다. 실제 본상품의 정가·판매가인지는 JSON만으로 확정하지 않는다.

## 발견된 문제

- 실제 상품명 DOM과 준비한 선택자가 맞지 않는다.
- 본상품 가격 영역을 특정하지 못하고 페이지 전체 금액을 수집한다. 추천 가격이 섞일 수 있다.
- 단위 가격 및 배송 금액이 일반 금액 후보에 포함됐다. 배송비는 해당 요소에 '배송'이라는 단어가 없어 단어 필터를 통과했다.
- 무신사는 역할 미확인 후보가 출력 제한인 30개에 도달했다. 본상품 가격을 포함했는지도 확정할 수 없다.
- 올리브영 이미지 후보에 배너가 포함돼 대표 이미지 영역을 좁혀야 한다.

## 다음 단계

이 결과로 '자동 기록 성공' 판정을 내리지 않는다. 본상품 요소의 DOM 위치를 확인할 수 있는 추가 테스트가 필요하다. 상품명·정가·판매가·대표 이미지를 사용자가 화면에서 선택해 해당 요소 위치를 진단하는 테스트 방식이 적합하다. 진단 결과를 바탕으로 사이트별 선택자를 수정하고 재검증해야 한다.

정식 저장·그래프·CSV·알림 기능은 구현하지 않았다. 사용자 확인 전 정식 구현을 시작하지 않는다.
