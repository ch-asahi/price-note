# 가격노트 설치와 사용법

**현재 버전: 1.1.0.** 기존 사용자는 [1.1 업데이트 안내](업데이트-1.1.md)를 확인하세요. 기존 폴더에서 확장 프로그램을 새로고침하면 데이터가 유지됩니다. 설정은 별도 화면으로 이동했고, 정상 기록은 2.5초 토스트, 실패/30% 이상 변동은 패널 확인 방식으로 바뀌었습니다. 14일 미만의 최저가·평균가는 —로 표시합니다.

무신사·올리브영 상품을 **내가 크롬에서 열었을 때** 가격을 기록하는 확장 프로그램입니다. 로그인·서버·네이버 API·Vercel·Supabase·GitHub Actions·API 키는 사용하지 않습니다. Node.js나 npm도 설치할 필요 없습니다.

## 1. 정식 확장 프로그램 설치

1. 크롬 주소창에 `chrome://extensions`를 입력하고 Enter를 누릅니다.
2. 이전 **가격 읽기 사전 테스트** 확장 프로그램은 스위치를 꺼 둡니다. 삭제할 필요는 없습니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 아래 폴더를 선택합니다. 파일 하나가 아니라 `manifest.json`이 바로 들어 있는 **price-tracker 폴더**를 선택해야 합니다.

   `압축을 푼 폴더\price-tracker`

6. **가격노트 · 무신사와 올리브영**, 버전 **1.1.0**이 나타나는지 확인합니다.
7. 크롬 오른쪽 위 퍼즐 모양 아이콘에서 가격노트를 고정합니다.
8. 이미 열려 있던 상품 페이지는 새로고침합니다. 설치 전에 열린 페이지에는 코드가 아직 들어 있지 않습니다.

ZIP 파일을 다른 PC로 옮겼다면 먼저 압축을 풀고, 그 안의 `price-tracker` 폴더를 선택합니다. 설치한 폴더는 옮기거나 지우지 마세요. 데이터는 폴더 자체가 아닌 Chrome의 로컬 저장 공간에 보관됩니다. 다른 PC·프로필·재설치 전에는 CSV 백업을 먼저 만드세요.

공식 설치 절차: https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world

## 2. 상품 등록 (최대 50개)

1. 무신사 또는 올리브영 상품 페이지를 평소처럼 엽니다.
2. 오른쪽 아래 **가격 추적 시작** 버튼을 누릅니다.
3. 상품명·정가·판매가가 화면과 일치하는지 확인합니다. 이미지 주소도 읽어 저장하지만 추가 요청을 막기 위해 목록에서 원격 이미지를 새로 표시하지 않습니다.
4. 정가가 따로 표시되지 않으면 정가 칸을 비워 둡니다. 판매가를 정가에도 넣지 않습니다.
5. **옵션 가격**을 선택합니다. 옵션이 없으면 옵션 없음, 모든 옵션 가격이 같으면 옵션별 가격 같음, 다르면 옵션 가격 다름을 선택합니다.
6. 옵션별 가격이 다르면 첫 번째 상품 옵션을 직접 선택하고, 첫 번째 옵션 이름을 입력합니다. '옵션을 선택하세요'는 옵션이 아닙니다. 품절인 첫 옵션을 임의로 두 번째 옵션으로 대체하지 마세요.
7. **공통 판매가** 확인에 체크합니다. 쿠폰·회원등급·카드 할인을 적용한 가격은 제외합니다.
8. 옵션별 가격이 다르면 첫 번째 옵션 가격 확인에도 체크합니다. 로그인 상태를 알면 선택하고, 모르면 미확인으로 둡니다.
9. **등록하고 오늘 가격 기록**을 누릅니다.
10. 크롬 도구 모음의 가격노트 아이콘을 눌러 상품이 나타나는지 확인합니다.

테스트 도구와 정식 확장 프로그램은 서로 다른 프로그램입니다. 테스트 JSON은 자동으로 가격 이력이 되지 않습니다. 실제로 등록한 날부터 기록합니다. 과거 가격을 만들어 넣지 않습니다.

## 3. 못 읽거나 다른 값을 읽었을 때

상품 페이지의 가격노트 패널에서 해당 **위치 지정** 버튼을 누른 뒤 화면의 값 하나만 클릭합니다. 읽은 위치는 쇼핑몰 호스트별로 저장되고, 등록 상품의 설정에도 보관됩니다. 크롬에서 그 상품을 다시 열 때 재사용합니다.

- 상품명: 이름 텍스트만 있는 작은 영역
- 대표 이미지: 대표 사진 자체
- 정가: 취소선이 있거나 정가/정상가 라벨이 있는 별도 가격
- 판매가: 쿠폰·회원·카드 할인을 뺀 일반 판매가 숫자
- 현재 선택한 옵션명: 화면에 표시된 **선택 완료된 첫 번째 옵션명**. 옵션 목록 전체나 '옵션 선택' 안내 문구를 고르지 마세요.

단위 가격(100ml당 등), 배송비, 쿠폰가, 카드·등급 혜택, 적립금으로 판별된 요소는 거부합니다. 같은 요소를 정가와 판매가로 중복 지정하는 것도 거부합니다. 위치를 못 읽어도 가격을 직접 입력하고 저장할 수 있습니다.

다른 상품의 화면 배치가 다르면 해당 상품에서 다시 지정하세요. 등록 상품별 위치 설정을 보관하므로 다른 상품의 재지정이 이미 등록한 모든 상품의 설정을 덮어쓰지는 않습니다. 사이트가 구조를 바꾸면 재지정이 필요할 수 있습니다.

## 4. 매일 기록되는 방식

- 등록한 상품을 다시 열거나 새로고침하면, 가격 표시가 안정된 뒤 자동으로 기록합니다.
- 날짜는 **한국 시간(Asia/Seoul)** 기준입니다.
- 같은 상품·날짜는 한 건입니다. 같은 날 다시 방문해 값이 바뀌면 마지막 기록으로 갱신합니다.
- 직접 보정한 값을 같은 방문의 자동 처리로 즉시 덮어쓰지 않습니다. 이후 새로 방문하면 다시 자동 읽기를 시도합니다.
- 페이지를 방문하지 않거나 읽기에 실패한 날은 가격을 만들어 채우지 않습니다.
- 정가를 못 읽거나 따로 표시하지 않으면 `null`로 보관합니다. 판매가로 대체하지 않습니다.
- 화면에 '가격 확인 필요' 또는 '가격 읽기 실패'가 표시되면 버튼을 눌러 확인하거나 직접 입력합니다.
- 배송비·옵션 추가금·쿠폰 혜택을 합산해 판매가로 추정하지 않습니다.

### 옵션 가격이 다른 상품의 중요한 조건

확장 프로그램이 옵션을 자동 클릭하면 쇼핑몰 요청이 발생할 수 있으므로 **옵션을 자동 선택하지 않습니다**.

첫 번째 옵션이 이미 선택되어 있는지, 또는 저장한 옵션명 위치에서 정확히 그 이름을 읽을 수 있는지 확인합니다. 옵션별 가격이 다르면 화면 판매가 위치도 지정해야 합니다. 숨은 데이터의 기본/최저 가격을 첫 번째 옵션 가격이라고 추측하지 않습니다.

선택 상태가 초기화되어 첫 번째 옵션을 확인할 수 없으면 자동 기록을 보류합니다. 이 경우 직접 첫 번째 옵션을 선택한 뒤 '현재 가격 다시 읽기'와 저장을 사용하세요. 따라서 **모든 옵션 상품이 클릭 없이 자동 기록된다고 보장하지 않습니다**. 가격이 같은 상품이나 옵션이 없는 상품은 기준 확인 후 일반적인 자동 방문 기록을 사용합니다.

## 5. 그래프와 판정 배지

팝업에서 상품을 선택하고 1개월(30일)·3개월(90일)·1년(365일)을 고릅니다. 정가는 점선, 판매가는 실선입니다. 미기록 날짜에는 선이 끊깁니다. 점에 마우스를 올리면 날짜와 값을 볼 수 있고, 기록 표에서도 확인할 수 있습니다. **넓게 보기**는 같은 관리 화면을 새 탭으로 엽니다.

- 현재가: 오늘 기록이 있으면 오늘 값. 없으면 '최근 기록가'로 표시하고 오늘 미기록 배지를 붙입니다.
- 역대 최저가·평균가: 실제로 기록된 모든 날짜의 판매가 기준입니다. 빈 날짜는 계산에서 제외합니다.
- 데이터 수집 중: 서로 다른 날짜의 기록이 14개 미만이거나 비교할 최근 중앙값이 없을 때입니다.
- 진짜 세일: 최근 기록일 **직전 90일**의 기록 중앙값보다 현재 기록가가 10% 이상 낮을 때입니다. 비교 기준에서 현재 기록 자신은 제외합니다.
- 평소 가격: 그 밖의 경우입니다.

방문 기록만으로 계산한 배지입니다. 미방문 날짜의 실제 최저가나 쇼핑몰 전체 가격 이력을 뜻하지 않습니다. 목록 표에는 최근 최대 366개 날짜가 보이고, CSV는 전체 기록을 내보냅니다.

## 6. 로그인과 옵션 표시

공통 판매가 기준으로 등록하더라도 로그인 상태에 따라 사이트 표시 값이 달라질 수 있습니다. 사이트의 표시 링크로 상태를 확인할 수 없으면 자동 기록의 로그인 상태는 미확인입니다. 이전에 비로그인이라고 입력했다고 이후에도 비로그인으로 단정하지 않습니다.

같은 상품·같은 옵션에서 15분 안에 로그인/비로그인 가격이 모두 관측되면 비교합니다. 값이 다르면 **로그인 전후 가격 다름**, 비교값이 없으면 **로그인 영향 미확인**으로 표시합니다. 시간차에 따른 가격 변동 가능성이 있으므로 로그인이 원인이라고 단정하지 않습니다. 로그인/로그아웃은 사용자가 직접 합니다. 쿠키나 계정 관심상품은 읽지 않습니다.

옵션 가격이 다르다고 설정하거나 숨은 옵션 가격 표에서 차이가 확인되면 **옵션 가격 다름**으로 표시합니다. 가격 종류나 옵션 상태를 확정하지 못하면 자동 저장을 보류하고 확인을 요청합니다.

## 7. 저녁 알림

기본은 매일 **오후 8시(한국 시간)**입니다. 설정에서 오후 5~11시로 바꾸거나 끌 수 있습니다.

- '오늘 기록 안 된 상품 N개' 알림의 **전부 열기**를 누르면 미기록 상품만 새 탭으로 엽니다.
- 팝업의 **미기록 전부 열기**도 같은 동작입니다.
- 상품을 열어도 옵션 확인이나 읽기가 실패하면 기록되지 않을 수 있습니다. 해당 페이지 안내를 확인하세요.
- 오늘 모두 기록했다면 알리지 않습니다. 자동 저녁 알림은 한국 날짜당 한 번만 보냅니다.
- PC가 잠자거나 Chrome이 꺼져 있으면 정각에 알리지 못할 수 있습니다. 같은 날 저녁 재실행하면 누락 여부를 확인합니다. 다음 날 아침에 전날 알림을 소급해서 보내지는 않습니다.
- Windows 알림/방해 금지 설정에 따라 알림과 버튼이 보이지 않을 수 있습니다. **설정 → 알림 테스트**로 확인하고, 버튼이 안 보이면 팝업의 전부 열기를 쓰세요.

Chrome의 알람 지연 특성: https://developer.chrome.com/docs/extensions/reference/api/alarms

## 8. CSV 백업과 복원

가격 기록이 있고 내보내기 이력이 없거나 마지막 CSV 내보내기 요청 후 7일이 지나면 앱에 **백업 권장**을 표시합니다. 실제 파일 저장 여부는 다운로드 폴더에서 확인하세요. CSV 가져오기는 내보내기 시각을 초기화하지 않습니다.

1. 팝업 아래 **CSV 내보내기**를 누릅니다.
2. 다운로드 폴더의 `가격노트-날짜.csv`를 안전한 곳에 보관합니다.
3. 복원할 때 **CSV 가져오기**를 누르고 파일을 선택합니다.
4. 상품 수와 기록 수를 확인한 뒤 **가져오기**를 누릅니다.

상품 정보, 가격 기준·상품별 위치 설정, 날짜별 정가·판매가, 읽기 방법, 로그인·옵션 정보가 포함됩니다. 알림 시각과 사용 설정은 복원 후 따로 설정하세요. 기존 상품과 합치며 같은 상품·같은 날짜는 기록 시각이 더 늦은 값을 사용합니다. 기존 상품의 이름·설정은 유지합니다. 형식 오류나 50개 초과가 있으면 전체 가져오기를 거부해 기존 데이터를 유지합니다. 정가 빈칸도 보존합니다.

UTF-8 CSV를 사용하며 엑셀에서 수식처럼 실행될 수 있는 이름은 내보낼 때 보호 처리합니다. 원본 백업은 엑셀에서 편집하지 않고 보관하는 것을 권합니다.

확장 프로그램을 삭제하면 Chrome 로컬 저장 데이터도 삭제됩니다. 같은 폴더에서 확장 프로그램을 **새로고침**하는 것은 삭제·재설치와 다릅니다. Chrome 프로필이 다르면 저장 공간도 다릅니다.

Chrome 로컬 저장 안내: https://developer.chrome.com/docs/extensions/reference/api/storage

## 9. 설치 후 직접 확인할 순서

1. 세일 상품 하나를 등록하고 팝업에서 오늘 가격을 확인합니다.
2. 같은 상품을 새로고침하고 날짜별 행이 한 개인지 확인합니다.
3. 판매가만 표시된 상품을 등록해 정가가 빈칸인지 확인합니다.
4. 옵션별 가격이 다른 상품에서 첫 번째 옵션과 판매가 위치를 지정하고, 다른 옵션 상태에서는 보류되는지 확인합니다.
5. 오늘 가격 직접 입력으로 보정한 뒤 기록 표를 확인합니다.
6. CSV 내보내기 후 같은 파일을 가져와 상품·기록 수가 늘어나지 않는지 확인합니다.
7. 설정에서 알림 테스트를 누릅니다.

## 검증 상태

코드 구문, 파서·금액 제외 규칙·정가 없음, 한국 날짜, 하루 한 건 갱신, 중앙값 판정, 그래프 빈 날짜, CSV 왕복·병합·50개 제한, 동시 저장, 로그인 비교, 알림 중복 방지를 자동 테스트했습니다.

정식 버전을 실제 Chrome에 설치한 통합 테스트와 화면 확인은 아직 하지 못했습니다. 컴퓨터 사용 도구가 현재 Chrome 주소를 안전하게 확인하지 못해 UI 조작을 중단했습니다. Windows 알림도 실제 전달 여부는 위 알림 테스트로 확인해야 합니다. 이전 사전 테스트에서 실제 사이트의 읽기 가능성을 확인한 것과 정식 버전 설치 검증은 구분합니다.

## 코드를 수정하게 된다면

- `readers/musinsa.js`: 무신사 필드명·전역 변수 목록·기본 읽기 설정
- `readers/oliveyoung.js`: 올리브영 필드명·검증한 기본 가격 위치
- `readers/hidden.js`: 공통 메타·JSON-LD·페이지 JSON 검사. 추천·리뷰·큐레이션·계정/장바구니 하위 데이터는 건너뜁니다.
- `readers/dom.js`: 표시 여부·금액 필터·정가 근거·클릭 위치 재사용
- `content.js`: 상품 페이지 버튼·위치 지정·방문 시 자동 기록
- `background.js`: 로컬 저장, 직렬 쓰기, 알림, 탭 열기
- `lib/core.js`, `lib/csv.js`, `lib/chart.js`: 가격 규칙·백업·그래프
- `app.html`, `app.js`, `app.css`: 팝업과 관리 탭

사이트별 필드명과 선택자는 해당 사이트 파일부터 수정합니다. 사이트의 UI 동작 자체가 크게 바뀐 경우에는 공통 옵션/클릭 처리도 보완해야 합니다. 코드를 바꾼 뒤에는 `chrome://extensions`에서 가격노트의 새로고침 버튼을 누르고 상품 페이지도 새로고침합니다.

개발자가 Node.js를 이미 갖고 있다면 상위 폴더에서 아래 세 명령으로 검사합니다. 일반 사용자는 실행할 필요 없습니다.

```text
node price-tracker/tests/core.test.cjs
node price-tracker/tests/readers.test.cjs
node price-tracker/tests/background.test.cjs
```

`preview.cjs`와 `app.html?demo=1`은 개발용 예시 화면입니다. 일반 사용에는 필요 없고, 예시 가격은 실제 기록으로 저장되지 않습니다.
