# 가격노트 (price-note)

**가격 기록 → 진짜 세일 판정.** 무신사·올리브영 상품을 직접 열었을 때 공통 판매가와 정가를 내 PC에 기록하는 Chrome 확장 프로그램입니다. 쇼핑몰의 표시 할인율과 내가 쌓은 실제 가격 기록을 함께 비교합니다.

## 할 수 있는 일

- 최대 50개 상품의 날짜별 가격 기록, 그래프, 최저가·평균가 확인
- 서로 다른 날짜의 기록이 14개 이상이고 비교 기준이 있을 때, 최근 기록일 직전 90일의 판매가 중앙값보다 10% 이상 낮으면 **진짜 세일** 표시
- 미기록 상품 확인과 저녁 알림, 가격 직접 보정
- CSV 내보내기·가져오기, 마지막 내보내기 후 7일이 지나면 **백업 권장** 표시

방문하지 않은 날짜는 빈칸으로 남습니다. 같은 상품·날짜는 마지막 기록 한 건을 유지합니다. 14개 날짜 미만이면 최저가·평균가도 표시하지 않습니다. 판정은 내가 기록한 가격에 대한 비교이며, 쇼핑몰 전체 이력이나 미방문 날짜의 최저가를 의미하지 않습니다. 쿠폰·등급·카드 할인은 공통 판매가에서 제외합니다. 옵션별 가격이 다르면 첫 번째 옵션 확인과 판매가 위치 지정이 필요할 수 있습니다.

## 왜 서버 수집 대신 확장 프로그램인가요?

사전 검토에서 일반 HTTP 요청으로 무신사·올리브영 상품 페이지와 robots.txt를 요청했지만, 이 요청 환경에서는 **403 차단 응답**을 받았습니다. 실제 상품 HTML과 수집 규칙을 확인할 수 없었습니다. 모든 환경에서 접근 불가능하다는 뜻은 아닙니다.

차단을 우회하기 위해 프록시, 사용자 에이전트 위장, 캡차 풀이 등을 사용하지 않기로 했습니다. 대신 사용자가 평소처럼 직접 연 상품 페이지에서 이미 제공된 화면·메타 정보·페이지 데이터를 읽습니다. 별도 수집 서버, 백그라운드 가격 요청, 자동 옵션 클릭을 사용하지 않습니다. 확장 프로그램도 사이트 구조가 바뀌거나 가격 기준을 확인할 수 없으면 읽기에 실패할 수 있습니다. 이때 위치를 다시 지정하거나 직접 기록합니다.

가격 기록은 Chrome의 로컬 저장 공간에 보관합니다. 계정 가입, API 키, 서버 운영이 필요 없으며 다른 PC로 자동 동기화하지 않습니다. [사전 검토 기록](docs/research/사전-테스트-결과.md)은 당시의 조사 이력입니다.

## 다른 컴퓨터에 설치하기

1. 이 GitHub 저장소에서 **Code → Download ZIP**을 누릅니다.
2. ZIP의 압축을 완전히 풀고, 계속 보관할 폴더에 둡니다.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
6. 압축을 푼 폴더 안의 **`price-tracker`**를 선택합니다. `manifest.json`이 바로 들어 있는 폴더입니다. `docs` 안의 사전 테스트 확장 프로그램과 구분하세요.
7. Chrome의 퍼즐 아이콘에서 가격노트를 고정하고, 열려 있던 상품 페이지는 새로고침합니다.
8. 상품 페이지 오른쪽 아래 **가격 추적 시작**에서 가격·옵션 기준을 확인하고 등록합니다.

Chrome 120 이상을 사용합니다. 일반 설치에는 Node.js나 npm이 필요 없습니다. 설치한 폴더는 옮기거나 삭제하지 마세요. 기존 설치를 업데이트할 때는 CSV를 먼저 내보낸 뒤 같은 `price-tracker` 폴더의 파일을 갱신하고 확장 프로그램의 새로고침 버튼을 누르세요.

[Chrome 공식 설치 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world) · [자세한 설치와 사용법](price-tracker/설치와-사용법.md)

## 기록을 새 PC로 옮기기

1. 기존 PC의 가격노트에서 **CSV 내보내기**를 누릅니다.
2. 다운로드 폴더에 `가격노트-날짜.csv`가 저장됐는지 확인합니다.
3. USB 등으로 CSV 파일을 새 PC에 옮깁니다.
4. 새 PC에 위 방법대로 확장 프로그램을 설치합니다.
5. 가격노트에서 **CSV 가져오기**를 눌러 파일을 선택합니다.
6. 상품 수·기록 수를 확인하고 **가져오기**를 누릅니다.

기존 기록과 합치며, 같은 상품·날짜는 기록 시각이 더 늦은 값을 사용합니다. 기존 상품의 이름·설정은 유지합니다. 알림 시각은 새 PC에서 따로 설정하세요. 확장 프로그램을 삭제하거나 Chrome 프로필을 바꾸기 전에도 먼저 CSV를 백업하세요. GitHub에 코드를 올리는 것만으로 내 가격 기록이 백업되지는 않습니다.

가격 기록이 있고 내보내기 이력이 없거나 마지막 내보내기 후 7일(168시간)이 지나면 앱에 **백업 권장**이 표시됩니다. 열린 화면에서는 1분 간격으로 갱신합니다. 내보내기 시각은 이 PC에 저장하고, CSV 가져오기는 그 시각을 초기화하지 않습니다. 추가 다운로드 권한을 요청하지 않기 때문에 시각은 **다운로드 요청 기준**입니다. 저장을 취소하거나 다운로드가 차단됐다면 다시 내보내고 실제 파일을 확인하세요.

## 폴더 구조와 개발 검증

```text
price-tracker/                 정식 확장 프로그램과 자동 테스트
docs/archive/price-reader-test/ 사전 검사용 확장 프로그램 (개발 이력)
docs/research/                 사전 조사와 테스트 결과 문서
docs/screenshots/              README에 넣을 화면 캡처
```

CSV·개인 테스트 JSON·원본 응답·배포 ZIP은 `.gitignore`로 제외합니다. 개인 테스트 JSON은 `price-read-test-*.json`, `personal-test*.json`, `*.local.json` 이름이나 `private/`, `test-results/` 폴더를 사용하세요. 개발용 테스트 코드는 정식 코드의 `tests/`에 둡니다.

Node.js가 설치된 개발 환경에서는 저장소 최상위 폴더에서 실행합니다.

```powershell
Get-ChildItem price-tracker/tests/*.test.cjs | ForEach-Object { node $_.FullName; if ($LASTEXITCODE -ne 0) { throw '테스트 실패' } }
```

자동 검증과 실제 Chrome 동작 확인은 별개입니다. 실제 사이트 읽기·Windows 알림·CSV 다운로드는 설치 후에도 확인하세요. 공개 업로드 순서는 [GitHub 업로드 안내](docs/GitHub-업로드.md)를 참고하세요.
